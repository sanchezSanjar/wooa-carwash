# Wooa Carwash

Car wash platform.

## Structure

- `backend/` — NestJS API (MongoDB Atlas, Mongoose, JWT)
- `mobile/` — React Native app (Expo, TypeScript)

## Backend

```bash
cd backend
cp .env.example .env
npm install
npm run start:dev
```

## Mobile

```bash
cd mobile
cp .env.example .env
npm install
npm start
```

Scan the QR code with the Expo Go app on your phone.
